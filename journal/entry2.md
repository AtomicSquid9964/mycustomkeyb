
# Entry 2: Complete 5x15 Matrix Tailored for 65% Layout

Massive progress today. I optimized the full schematic grid matrix in KiCad down to a custom 5x15 setup, which perfectly accommodates the 68 keys needed for my 65% gaming layout. 

I manually trimmed out the unnecessary columns and switches from the right side of the sheet to keep my schematic perfectly clean. I caught an accidental short-circuit junction dot connecting a vertical column wire directly to a horizontal row line next to SW70, and cleanly removed it so the signals safely isolate through individual anti gosting diodes instead. Next up is running these row and column highways directly into the Raspberry Pi Pico pins
