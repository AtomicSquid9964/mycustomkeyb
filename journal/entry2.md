# Entry 2: Complete 8x9 Matrix Stacked and Ready

Massive progress today. I built out the full 8x9 schematic grid matrix in KiCad. By setting up the first master row with individual anti-ghosting diodes and running a parallel row highway, I was able to duplicate the blocks down cleanly. 

Leaving a wide gap between rows worked perfectly, the vertical column lines snapped into place without crossing or tangling the horizontal row lanes. The matrix looks clean, and next up is running the row and column highways directly into the Raspberry Pi Pico pins!
